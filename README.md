# ANNU PREMIUM HAMPERS — Complete Front-End Website

## Included
- Premium responsive homepage
- Occasion categories
- Product catalogue with sample images
- Search and category filtering
- Add to cart
- Quantity update/remove
- Persistent cart using localStorage
- Checkout/customer information form
- Demo order confirmation
- Mobile responsive navigation
- SEO title/description

## Run locally
Open `index.html` in any modern browser.

## Customize
Edit the `products` array in `script.js` to change names, prices, categories and product images.

## Before accepting real payments
This is a front-end website. The checkout currently demonstrates the UI/order flow only. For a live store, connect:
1. A secure backend/database for orders.
2. A payment gateway such as Razorpay/Stripe or another provider available to your business.
3. Your real shipping/delivery rules.
4. Your WhatsApp/business contact details.
5. Your own product photos hosted in `assets/` or your website/CDN.

Do not put payment gateway secret keys in `script.js` or other browser-side files.
