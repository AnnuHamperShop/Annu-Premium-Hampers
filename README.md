# Annu Premium Hampers

A responsive hamper-store website with:
- Product catalogue
- Category filtering
- Add to cart
- Quantity controls
- Local cart storage
- Checkout/customer details form
- Demo order confirmation

## Run
Open `index.html` in a browser.

## Important before real orders
The included checkout is a front-end demo. For real online payments and order storage, connect a payment gateway and secure backend/database. Replace the sample product images, names and prices with your actual catalogue.
